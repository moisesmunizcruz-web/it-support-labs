# it-support-labs

## English

This portfolio documents self-directed, simulated IT support practice in a personal lab. It is not professional production experience.

### Lab environment

- Host: Windows 11 Pro with Hyper-V.
- Virtual machine: `Ubuntu-Support-Lab` running Ubuntu Desktop LTS.
- Network: Hyper-V Default Switch with NAT internet access.

### Repository contents

- `lab-notes/`: completed technical exercises and validation.
- `support-cases/`: simulated incidents and service requests.
- `knowledge-base/`: short troubleshooting guides.
- `evidence/`: reviewed screenshots with sensitive information removed.

The lab focuses on user support, basic system administration, networking, troubleshooting, and clear documentation. Each completed exercise records its objective, steps, result, validation, and lessons learned.

## Español

Este portafolio documenta prácticas autodirigidas y simuladas de soporte TI realizadas en un laboratorio personal. No representa experiencia profesional en producción.

### Entorno del laboratorio

- Equipo anfitrión: Windows 11 Pro con Hyper-V.
- Máquina virtual: `Ubuntu-Support-Lab` con Ubuntu Desktop LTS.
- Red: Default Switch de Hyper-V con acceso a Internet mediante NAT.

### Contenido del repositorio

- `lab-notes/`: ejercicios técnicos completados y su validación.
- `support-cases/`: incidentes y solicitudes simuladas.
- `knowledge-base/`: guías breves de solución de problemas.
- `evidence/`: capturas revisadas, sin información sensible.

El laboratorio se enfoca en soporte a usuarios, administración básica de sistemas, redes, diagnóstico y documentación clara. Cada ejercicio completado registra su objetivo, pasos, resultado, validación y aprendizaje.
